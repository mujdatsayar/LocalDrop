# LocalDrop 1.1.0

LocalDrop 1.1.0 adds a complete Turkish and English experience to the desktop dashboard, phone pairing flow, and connected mobile interface. Use the single **TR / EN** control to switch instantly; the choice is remembered on each device.

## Included in this release

- Persistent Turkish/English language switching across every user-facing screen
- Localized dynamic file counts, transfer status, timestamps, dialogs, errors, and accessibility labels
- Updated English and Turkish screenshots with private IP addresses, pairing URLs, and QR codes redacted
- Rebuilt Windows installer and portable x64 package
- Rebuilt macOS Apple Silicon DMG and portable application archives
- Localization tests added to the existing security and transfer test suite
