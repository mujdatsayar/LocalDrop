# LocalDrop 1.0.0

The first public release of LocalDrop provides private, two-way file transfer between a computer and phone on the same trusted Wi-Fi network. Files move directly through the local network: no account, cloud upload, or mobile app is required.

## Included in this release

- Windows installer and portable x64 package
- macOS Apple Silicon DMG and portable application archives
- A self-contained macOS setup bundle that can rebuild and install the app
- Desktop and mobile web interfaces with QR/PIN pairing
- Multiple-file transfer, progress feedback, media preview, and automatic inbox refresh
- Five-minute PIN rotation, phone session locking, subnet filtering, rate limiting, and browser security headers
